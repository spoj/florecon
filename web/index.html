Plan node reference

A plan is {"primary":"<amount col>", "root":<node>}. primary is the conserved column reconciled to zero. Every node is {"op":"…", …}. Matchers form groups; combinators route rows into sub-nodes. A Sel is an int expression: a bare "col", a bare number, or {"gt":["amount",0]}, {"abs":"amount"}, {"in":["account",[4000,5000]]}, {"if":[cond,a,b]}. A Tol is a bare number (absolute) or {"bps":10,"floor":1} (relative).

Matchers (leaves)

exact{"op":"exact"}Pair equal-and-opposite amounts 1:1.
agg_net{"op":"agg_net","key":<Sel>,"tol":<Tol>}Group rows sharing key if they net to within tol.
signal{"op":"signal","signals":"ref","tol":0,"cap":256}Bind rows that share a reference/text token and net out.
flow{"op":"flow","day":"date","tokens":"ref","penalty":1000,"window":-1}Min-cost flow over near date/token; arbiter of last resort.

Combinators (route & label)

seq{"op":"seq","steps":[…]}Run nodes in order; each works on what's left.
partition{"op":"partition","by":<Sel>,"inner":<node>}Split rows by by, run inner within each bucket independently.
branch{"op":"branch","pred":<Sel>,"and_then":<node>,"or_else":<node>}Send rows where pred≠0 one way, the rest the other.
windowed{"op":"windowed","order":<Sel>,"width":7,"inner":<node>}Sliding window over order (e.g. date) before inner.
pivot{"op":"pivot","amount":<Sel>,"inner":<node>}Reconcile on a different numeraire under a conserving projection.
label{"op":"label","tag":"stage 3","inner":<node>}Stamp a why reason on every group inner forms.

Use the Insert node buttons above to drop a correct skeleton at the cursor, then edit the column names. Column names must match the engine name column you set; the engine validates them on Run.
